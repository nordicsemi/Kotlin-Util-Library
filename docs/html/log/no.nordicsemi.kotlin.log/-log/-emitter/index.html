Emitter

interface Emitter

An instance of this interface can produce logs.

Note, that this interface does not define a Sink. The library is free to choose a name for a log sink, or even have multiple sinks if necessary.

Example

class MyManager : Log.Emitter {
   var logger: Log.Sink<MyCategory>? = Log.Sink.Null

   fun doSomething() {
      logger?.info(MyCategory.A) { "Action performed" }
   }
}
